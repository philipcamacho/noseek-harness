# Noseek Fork Delta Ledger

This ledger records every upstream file modified or deleted in the `noseek-harness` fork relative to the upstream base.

Whenever an upstream file is modified, its presence in this ledger is mandatory. The `noseek/check-delta.sh` script enforces bidirectional consistency: every modified upstream file must have a ledger row, and every ledger row must correspond to an active upstream modification.

## Noseek-Owned Files (Non-Conflicting)

These files are owned by the Noseek distribution and do not exist in upstream:

- `.github/README.md`: Public-facing repository README rendered by GitHub. Keeps root `README.md` clean for upstream syncs and translation pairing gates.
- `.github/workflows/noseek-upstream-sync.yml`: Scheduled and manual workflow that detects new `dsh-v*` upstream tags, merges on `sync/<tag>`, runs all Noseek verification gates, and opens a PR targeting `master`.
- `noseek/WHITELABEL_PLAN.md`: Comprehensive whitelabel architecture, quarantine inventory, network isolation gates, and execution phases.
- `noseek/AGENTS.md`: Standing orders, fork invariants, and delta discipline for agents working in this repository.
- `noseek/DELTA.md`: This delta ledger.
- `noseek/CHANGELOG.md`: Chronological log of upstream tag merges and fork adjustments.
- `noseek/UNAUDITED_AREAS.md`: Code-level audit of `python/`, `native/`, and `vendor/` for network egress and telemetry.
- `noseek/PROVIDER_AUDIT.md`: Provider capability spike and feature comparison between `llm-pi-ai` and `llm-deepseek`.
- `noseek/check-delta.sh`: Verification script ensuring bidirectional consistency between modified upstream files and this ledger.
- `noseek/audit-privacy.ts`: Profile composition, hostile-override, and loopback BYOK privacy gate (`pnpm run audit:privacy`).
- `noseek/hermetic-network-test.ts`: Hermetic network gate verifying zero non-loopback DNS/TCP egress and clean model request payloads (`pnpm run test:hermetic`).
- `noseek/run-hermetic-test.sh`: Shell wrapper for running the hermetic network test under `unshare -rn` / `strace` / `docker --network none`.
- `noseek/sync-gates.spec.ts`: Vitest suite verifying Phase 5 upstream sync gate fixtures and workflow invariants.
- `packages/boot/app-boot/src/noseek-policy.ts`: Noseek defaults layer, final quarantine layer, blocked-host matcher, and boot/plugin-manager refusal logic.
- `packages/boot/app-boot/tests/noseek-policy.spec.ts`: Unit tests for `noseek-policy.ts`.
- `docs/upgrade-guide/v0.2.1-rc.3/noseek-home-and-provider-routes/guide.md`: English upgrade guide for `~/.noseek` home split and `deepseek-official` removal.
- `docs/upgrade-guide/v0.2.1-rc.3/noseek-home-and-provider-routes/guide.zh.md`: Chinese upgrade guide for `~/.noseek` home split and `deepseek-official` removal.
- `docs/upgrade-guide/v0.2.1-rc.3/noseek-home-and-provider-routes/guide.i18n.yaml`: Translation pairing metadata for the upgrade guide.
- `.agents/skills/noseek-upstream-sync/SKILL.md`: Operational skill guiding agents and contributors through upstream release tag syncs.
